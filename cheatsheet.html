Timeshift system snapshots

Rolls the system back after a bad update or config change. Your home folder is not included.

sudo timeshift --listShow snapshots
sudo timeshift --create --comments "before update"Take a snapshot now
sudo timeshift --restorePick a snapshot and restore it
sudo timeshift --deletePick a snapshot to delete
Timeshift appSame actions with a window: select, then Restore

Automatic: daily (keep 5), weekly (3), at boot (3). Won’t boot? Start from the Ubuntu USB, install Timeshift there and restore.

Backups home folder → Google Drive

Daily, encrypted, to Drive folder Backups/ubuntu-personal-laptop. Skips Downloads, Trash and ~/.cache.

deja-dup --backupBack up now
Backups app → RestoreBring back files from any date
Backups app → PreferencesFolders, schedule, how long to keep

Restoring needs your Google sign-in and the encryption password. Keep it off this laptop.

Don’t move or rename the backup folder in Google Drive; Déjà Dup only sees folders it created.

Backup workflow which one to use

Timeshift = the system, on this disk. Backups = your files, on Google Drive.

Update broke somethingTimeshift: pick a snapshot from before → Restore → reboot
Ubuntu won’t bootTimeshift from the Ubuntu USB live session
Deleted or overwrote a fileBackups → Restore → pick a date
Broke a config like ~/.zshrcBackups, or the copies in ~/Projects/system-setup/configs
Laptop lost or disk deadNew install → Backups → Restore → follow system-setup/README.md

Habits: snapshot before risky changes · monthly, check “Last backup” and restore one test file · keep important files out of Downloads.

Timeshift restores never touch your home folder. Backups skip days on metered connections or in power-saver mode.

zoxide smart cd

Learns the folders you visit. Match any part of the path.

z projJump to best match for "proj"
z api srcMatch several words, in order
z -Back to the previous folder
ziPick from all known folders with fzf
z proj SpaceTabShow matches before jumping
zoxide query -lList what it has learned
zoxide remove ~/oldForget a folder

It never jumps to the folder you are already in. New folders are learned the first time you cd into them.
